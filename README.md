# planbee landing

Бренд-лендинг `planbee` — системы, которая связывает два рабочих пространства:

- мобильное приложение для полевых замеров, фотофиксации и дефектов;
- компьютерную версию для подготовки ВОР и сметы.

## Структура

- `index.html` — одностраничный бренд-лендинг с анимированной hero-сценой (пчела дорисовывает план и собирает смету);
- `styles.css` — дизайн-система planbee: типографическая шкала, пунктирный «маршрут пчелы», сотовые паттерны, адаптив;
- `app.js` — цикл hero-сцены со счётчиками, reveal с фолбэком, вкладки ВОР/сметы, отправка формы;
- `functions/api/lead.js` — Cloudflare Pages Function для заявок в Telegram;
- `img/planbee-logo-v2.png` — основной логотип (мастер);
- `img/planbee-logo-trimmed.png` — обрезанная и облегчённая версия для шапки/подвала;
- `favicon.svg` — компактный знак (сота + фрагмент плана + пчела-точка);
- `hosting-static/og.png` — карточка для социальных сетей (кадр hero);
- `BRAND.md` — правила использования бренда.

## Локальный просмотр

```bash
npm run dev
```

Форма при таком просмотре не отправляет заявки: для неё нужен runtime Pages Functions.

## Приём заявок

Форма делает `POST /api/lead`. Сервер проверяет поля, отсекает honeypot и отправляет заявку в Telegram через Bot API.

Переменные окружения:

- `TG_BOT_TOKEN` — токен Telegram-бота;
- `TG_CHAT_ID` — chat id получателя.

Секреты не должны попадать в репозиторий. Для локальной проверки функции можно использовать `.dev.vars`, который добавлен в `.gitignore`.

## Деплой на Cloudflare Pages
