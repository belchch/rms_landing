# rms_landing

Статический лендинг RMS — платформы для строительно-технической экспертизы (фокус: споры по ДДУ). Аудитория — экспертные организации.

Продукт: `rms_platform` (backend + web), `rms_mobile` (Flutter-клиент).

Ветка `v2-mplan-like` — светлая «продуктовая» тема по структуре magicplan: герой с планом квартиры, блок осмотра, обмеры с лазерным дальномером (без сканирования), фотофиксация, смета, поле → офис.

Ветка `v3-mplan-like-boq` — развитие v2 вокруг идеи «два мира: замеры и отчёты»: лёгкие замеры дальномером → ведомость объёмов работ (ВОР) строится в приложении → смета материалов и работ → отчёты по дефектам, ВОР и смета.

## Структура

- `index.html` — вся разметка, одна страница
- `styles.css` — светлая тема, синий акцент, карточки
- `app.js` — reveal-анимации при скролле и живые значения дальномера

Без сборки и зависимостей. Открыть локально:

```bash
python3 -m http.server 8000
```

Деплой — любой статический хостинг (nginx, GitHub Pages, S3).
